1. Objective

Design, implement, and validate an object-oriented Java model for a campus smart-parking system using Java fundamentals and OOP concepts.

2. System Requirements

The system should support:

Multiple floors and parking slots.
Two-wheelers, cars, and electric vehicles.
Parking allocation and unique ticket generation.
Entry-time recording and slot release.
Parking fee calculation based on vehicle type and duration.
Free parking for eligible students and staff with valid monthly passes.
Separate EV charging slots and charges.
Extensible vehicle categories and pricing rules.
